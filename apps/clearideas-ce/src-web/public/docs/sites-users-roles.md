# Sites, Users, and Roles

A site is the main collaboration space. Sites contain folders, files, users, and settings.

## Roles

- Owner: controls the site and owns the workspace account.
- Admin: manages site settings and users.
- Editor: can manage folders and content.
- Uploader: can add content where permitted.
- Downloader: can access files for download/view workflows.
- Viewer: can view available site content.

## Site Visibility

Private sites are available only to invited users. Public sites are visible to users who can access the app, while write and admin actions remain role-gated.

## User Groups

User groups help organize people for management workflows. Groups do not replace site roles; site membership remains the permission source for site content.

## Invitations

Users can accept, decline, or suppress site invitations. Profile settings control auto-accept behavior for sites where that workflow is enabled.
